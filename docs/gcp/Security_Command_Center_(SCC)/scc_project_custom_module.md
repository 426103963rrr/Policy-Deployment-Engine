## Argument Reference
| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `display_name` | The display name of the custom module. This becomes the finding category for all findings returned by this module. | true | false | The display name is informational and helps analysts identify findings but does not affect security. | enablement_state |  |
| `enablement_state` | The enablement state of the custom module. Possible values: ENABLED or DISABLED. | true | true | If disabled, the module does not generate findings, leading to blind spots in monitoring. | ENABLED | DISABLED |
| `custom_config` | Custom configuration for the module, defining predicate logic, resource scope, severity, and recommendations. | true | true | The configuration defines how findings are generated. | `project` | The project where the custom module is defined. If omitted, the provider project is used. | true | false | Defines scope but does not directly impact security posture. | cefwed |  |

### custom_config Block
| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `predicate` | CEL expression that evaluates resources and generates findings when true. | true | true | Predicate logic defines detection conditions. Without it, no findings will be generated. | resource.rotationPeriod > duration("2592000s") |  |
| `resource_selector` | The resource types this custom module applies to. Can include up to 5 resource types. | true | true | Restricting modules to relevant resources ensures accurate findings. Empty or incorrect selectors may result in gaps. | ["cloudkms.googleapis.com/CryptoKey"] | [] |
| `severity` | The severity assigned to findings generated by the module. Valid values: CRITICAL, HIGH, MEDIUM, LOW. | true | true | Severity impacts prioritization in security workflows. Incorrect levels may delay critical remediation. | LOW |  |
| `recommendation` | Remediation guidance provided for each finding to assist security teams in resolving issues. | true | true | Without clear recommendations, security teams may be unable to remediate findings effectively. | Steps to resolve violation |  |
